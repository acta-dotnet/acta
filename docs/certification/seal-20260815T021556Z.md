**The two engines converged, again.** 574 orphaned attempts against PostgreSQL's 584, 72 workers
reclaimed dead against 73, identical job, step, and receipt totals to the row. The clock-backsteps
note diverges the other way this time — 117 here against 16,669 on PostgreSQL — which is the
standing argument for keeping it measured, never asserted: it tracks lock-wait patterns, not
correctness, and every asserted property passed on both.

**Stated plainly:** zero charges were interrupted mid-body this run (as on the PostgreSQL run), so
`at-most-once = 0` is vacuous here; the non-vacuous versions are the 0.8.0 ensemble seals and this
release's ensemble run.

namespace in the schema — the 3-participant / 2-namespace ensemble seal covers that. The checks are
