## Scope

One machine, one namespace, one SQLite file, Direct profile only. SQLite is single-node, so multi-process namespace isolation is out of scope here and carried by the ensemble seal; what this gate proves is that the single-writer provider holds every other property at 48 slots under the same kill cadence. Checks are `anvil/Anvil/certify.sql` bound to `certr5sq` plus the `rate-contract` window scans in `CertifyVerdict`; re-run `anvil certify` against that file to reproduce the verdict.
