## The check that caught the 0.9.0 defect, at zero rows

`expected-outcome` is the check that failed on this provider in the 0.9.0 round: one `slow-success`
job out of fifteen thousand landed terminal **Failed** with no reason recorded, because the
executor's ownership-lost path set a null failure reason and a null reason is not retryable. The fix
(`8f03356`) submits a retryable `job.attempt-aborted` failure instead, so a row this worker still
owns re-arms under the failure budget and replays its recorded steps.

This run is that fix still holding four commits of adversarial review later, under the same chaos:
576 orphaned attempts against the fixed 0.9.0 run's 573, 72 workers reclaimed dead against 72, and
`expected-outcome` at zero rows. Nothing in this schema terminalized Failed at all — 15,000 of 15,000
seeded jobs reached `Succeeded`.

## Scope — reduced, and stated on its face

- **Single machine is the engine's deployment model, not a shortcut**: SQLite is embedded, so every
  worker shares the database file by construction. Kills, leases, reclaim, and multi-*process* claim
  contention are fully exercised; multi-*machine* topology claims are out of scope on this provider
  permanently, not merely untested.
- **One namespace, one participant**: `namespace-isolation` passes but cannot fail with a single live
  namespace in the database; the 3-participant / 2-namespace ensemble seal covers that (on a server
  engine — the ensemble shape presumes independent participant processes joining one database, which
  is the server providers' deployment model).
- Concurrency is 48 slots against the server engines' 64: the single write lock makes more executors
  contention rather than throughput; the run certifies the shipped SQLite guidance (`Direct` profile,
  WAL), not a server-class concurrency envelope.
- **The 0.9.0 fix still carries no direct unit pin** — no executor harness exists to drive that catch
  in isolation, which remains a post-release item. The evidence it has is the failing run, the
  re-run against the fix, and now this run.
