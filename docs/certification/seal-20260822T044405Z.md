**The two engines converged, again.** 576 orphaned attempts against PostgreSQL's 584, 72 workers
reclaimed dead against 73, identical job, step, and receipt totals to the row — and 576/72 is within
two of the pair this engine produced on the 0.9.0 round (574/72), which is the second convergence
worth naming: the re-cut moved nothing. The clock-backsteps note diverges the other way as it always
does — 182 here against 17,308 on PostgreSQL — which is the standing argument for keeping it
measured, never asserted: it tracks lock-wait patterns, not correctness, and every asserted property
passed on both.

**Stated plainly:** zero charges were interrupted mid-body this run (as on the PostgreSQL run), so
`at-most-once = 0` is vacuous here; all 1,000 charges wrote exactly one witness note. The non-vacuous
version is this round's ensemble seal.
