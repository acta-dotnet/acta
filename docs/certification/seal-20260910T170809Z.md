## The backsteps note

`clock-backsteps` counts writes whose recorded instant is not after the instant already on the row.
PostgreSQL reads 15,393 here, and the figure is a property of the clock rather than of the engine:
`now()` is transaction start time, so every statement inside one transaction shares an instant.
`events.created_at_utc` is documented as the instant the row was written and explicitly not as a
commit order, which is what makes this a note rather than a failure.

## Scope

One namespace, one machine, one PostgreSQL schema. The checks are `anvil/Anvil/certify.sql` with the
schema token bound to `certrc2npg`; re-run them against that schema to reproduce the verdict. This
gate does not measure throughput: it counts outcomes under kills. Namespace isolation is asserted
here but cannot fail on a single-namespace run — the ensemble seal of the same round is where that
check carries weight.
