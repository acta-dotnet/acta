## Why this round exists

A seal certifies a commit. The four 0.9.0 seals certify `8f03356`, which `v1.0.0-rc.1` does not
ship. `e016156` is the near-final rc.1 commit, taken after the adversarial review wave that closed
out the release candidate, so all four gates were re-run against it from empty schemas at the same
shapes the 0.9.0 round used. This is the first of that round. The tree under chaos differs from
0.9.0's by the whole of rc.1 — the re-cut `baseline-1.0` schema, incident-identity alerting behind
its new projection horizon, durable wait deadlines, and the startup preflights — while the shapes
stay identical, so the numbers remain comparable run over run.

The outbox split-check design — the staging table lives in the producer's database, so *drained* and
*delivered* are Anvil's to prove and `outbox-relayed-outcome` is the ledger's — is unchanged here,
and certified again under the same chaos: the 5,000 rows were staged in small committed batches
spread across the whole kill window, so relay claims raced worker kills the entire time.

**The rc.1 round reproduced the 0.9.0 round to within scheduling luck**: 584 orphaned attempts
against that seal's 579, 73 workers reclaimed dead against 73, identical job, step, and receipt
totals to the row. Nothing in the adversarial wave moved a number here, which is what a wave that
touched documentation, tests, and infrastructure rather than the execution path should look like on
the engine.

**Stated plainly:** zero charges were interrupted mid-body this run, so `at-most-once = 0` is vacuous
here — no kill happened to land inside a charge body among the 584 orphaned attempts. All 1,000
charges wrote exactly one witness note and none wrote two. The non-vacuous version of that claim is
this round's ensemble seal, which interrupted 47.

## Scope

One namespace, one machine, one participant. The schema holds two namespace rows — the reserved
`sys` row, which owns no jobs, and the run's own — so `namespace-isolation` runs schema-wide and
passes but cannot fail; the 3-participant / 2-namespace ensemble seal covers that. The checks are
`anvil/Anvil/certify.sql` with the schema token bound to `certrc1pg`; re-run them against that schema
to reproduce the verdict.
