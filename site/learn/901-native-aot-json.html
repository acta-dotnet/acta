How to run jobs under Native AOT

A source-generated JsonSerializerContext given to UseJsonPayloads serializes payloads with no runtime reflection, and JobPayload.Json(value, typeInfo) builds a raw payload the same way. The program runs on the JIT: it shows the registration an AOT publish needs, and the publish itself is proven by the repository's own gate.

A how-to for Acta, durable execution for .NET. New to Acta? Run your first durable job in five minutes.

1Declare a source-generated context for the payload types

Source-generated context: covers every job input and result type so no runtime reflection is needed under Native AOT. Wired via j.UseJsonPayloads(AotPayloadContext.Default). The two options give enums the wire shape a JIT host writes (camelCase strings), so an AOT worker reads what a JIT producer enqueued.

2Hand the context to Acta

Wire the source-generated resolver so payload (de)serialization needs no reflection.

3Build a raw payload with its type info

JobPayload.Json(value, typeInfo) is the AOT-safe path: the JsonTypeInfo comes from the source-generated context so no runtime reflection touches the payload type. The program enqueues process-order with it, which prints the order.
